# Current Tagging Plan Maybe

A tool to help with deterministic AI code reviews for developers,
or just general function tagging

## Simple Overview

Names are not final and subject to change
(Timestamps will be probably be replaced with UTC timestamps)

```python
def foo():
  """
  [Needs Review by: Codex]
  [Function hash: b67f95ba0bf]
  Foo foo foo
  """
  return None

def bar():
  """
  [Last Reviewed: 14:00:32 | Bob]
  [Function hash: 54f93b3905951]
  Bar bar bar
  """
  return None
```

General Command with --file argument and not other arguments
returns all Tags for a file

```bash
uv run tagger.py --file_path myfile.py

```

Expected output:

```bash
[INFO] "Function foo returned [Needs Review by: Codex]"
[INFO] "Function bar returned [Reviewed: 14:00:32 | Bob]"
```

Other expected commands:

```bash
uv run tagger.py --file_path myfile.py --tag "Needs Review"
```

This should return all functions tagged with `"Needs Review"`
Tagger should have multiple command line arguments and be case insensitive\

## Function Tagging

```bash
uv run tagger.py --add "{Tag_name}" --function_name "{function_name}" --file_path "{file_path}"
```

Running this command should add the tag to function in the given file path.

## Planned Command Line Arguments

```bash
--check # Check file/directory for tags marked as important
--strict # Should raise error on any missing tagged functions, used after --check arg
--add # Should add a function tag (Raise error if tag does not exist)
--function_name # Specify a function name
--new_tag # Generate a new tag to the tags.json file
--file_path # Specify a file path (Raise not found error, etc.)
--dir_path # Specify a directory path (Raise not directory or not found error, etc.)
```
